# WasteWise AI — Skills Directory

Reusable "how-to" procedures for common tasks. Created as patterns
emerge during the build. Each `.md` file is one skill.

## Usage

When a procedure has been done 3+ times (per `loops.md`), write it here
as a skill file. Skills are loaded on-demand by Antigravity.

## Planned skills (will be created as Phase 1+ progresses)

- `fastapi-router.md` — How to add a new FastAPI router + service + schema
- `alembic-migration.md` — How to add a new Alembic migration
- `react-page.md` — How to add a new page/route with design tokens
- `ai-module.md` — How to add a new AI module with heuristic fallback
