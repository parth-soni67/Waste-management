# WasteWise AI

## Project Objective
WasteWise AI is a next-generation municipal waste management platform that leverages AI-driven computer vision, multi-agent evaluation, and dynamic routing to optimize the detection and cleanup of public waste. It bridges the communication gap between citizens and municipal authorities, automating dispatch logic to reduce fuel costs, minimize response times, and prevent street-level waste accumulation.

## Key Features
- **Citizen Service Portal:** An intuitive interface for citizens to report waste. Includes WebRTC-enforced live camera capture (preventing fraudulent or outdated photo uploads from the device gallery) and live GPS location tagging.
- **AI Computer Vision Engine:** Instantly analyzes uploaded photos to classify waste categories, estimate physical volume (m³), and generate a priority severity score (0-10) before a human even reviews it.
- **Officer & Admin Command Center:** A MapLibre-powered spatial dashboard for municipal officers. Features real-time incident clustering, AI recommendations, manual overrides for severity and truck assignment, and one-click dispatching.
- **Smart Fleet Management:** Comprehensive dashboard to manage municipal trucks and drivers. Embedded logical safeguards prevent active (loaded) trucks from going into maintenance, ensuring waste is never orphaned on the streets.
- **Dynamic AI Routing:** Utilizes OSRM (Open Source Routing Machine) architecture to solve the Traveling Salesperson Problem (TSP), dynamically routing trucks to incident hotspots for maximum geographic efficiency.
- **Financial Analytics Dashboard:** Calculates and visualizes real-time ROI, including fuel expense tracking, maintenance costs, wage reductions, and total savings generated by AI-optimized routing.

## Technology Stack
- **Frontend (Web):** Next.js (React App Router), Tailwind CSS, Lucide React, MapLibre GL JS, WebRTC API.
- **Backend (API):** Python FastAPI, SQLAlchemy (ORM), Alembic (Database Migrations).
- **Database:** PostgreSQL (with PostGIS extension for spatial mapping).
- **AI & Logic Layers:** Custom CV Pipeline, Multi-Agent LLM System (Municipal/Verification Agents), and OSRM for dynamic geographic routing.

## Setup/Installation Instructions

### Prerequisites
- Node.js (v18+)
- Python (v3.10+)
- PostgreSQL installed and running

### 1. Database Setup
Create a PostgreSQL database for the project. Copy the `.env.example` to `.env` in your `apps/api` folder and update the `DATABASE_URL` with your local credentials.

### 2. Backend Setup (FastAPI)
Navigate to the API directory, install dependencies, and start the server:
```bash
cd apps/api
python -m venv venv
source venv/bin/activate  # On Windows use `venv\Scripts\activate`
pip install -r requirements.txt
alembic upgrade head      # Run database migrations
uvicorn app.main:app --reload --port 8000
```

### 3. Frontend Setup (Next.js)
Open a new terminal, navigate to the web directory, install dependencies, and start the development server:
```bash
cd apps/web
npm install
npm run dev
```
The frontend will be available at `http://localhost:3000`.
